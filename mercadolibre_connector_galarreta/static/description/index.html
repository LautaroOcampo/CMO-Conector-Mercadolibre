Como funciona

Cinco pasos para dejar la operacion andando.

1 Instalar y abrir la configuracion de Mercado Libre
Aparece un menu propio dentro de Ventas.
2 Cargar el App ID y el Client Secret
Salen de tu aplicacion en el portal de desarrolladores de Mercado Libre.
3 Autorizar con OAuth 2.0
Los tokens se guardan en tu base y se renuevan solos.
4 Importar publicaciones y vincularlas por SKU
Matching automatico por SKU o asignacion manual, con variantes.
5 Activar los webhooks
Cada venta genera pedido, entrega y factura en Odoo.

Que se sincroniza

De Odoo a Mercado Libre y de Mercado Libre a Odoo, segun la operatoria.

Area Odoo a Mercado Libre Mercado Libre a Odoo
Publicaciones Alta, precios y stock Importacion y vinculo por SKU
Stock Cantidad, pausa y reactivacion Mercado Libre Full
Ventas La venta queda registrada en Odoo Pedidos, packs y cancelaciones
Facturacion Factura, nota de credito y comisiones en Odoo Datos del comprador para el tipo de factura

Por que operarlo dentro de Odoo

  • Las ventas no quedan en una planilla aparte del stock
  • El precio y la publicacion salen del mismo producto
  • La factura se emite con el pedido, no al dia siguiente
  • Una cancelacion puede generar la nota de credito
  • Las comisiones de Mercado Libre quedan como asiento aparte
  • Varias cuentas conviven en la misma base

Servicio externo y privacidad

El modulo usa la API de Mercado Libre. Hace falta una cuenta de vendedor activa y una aplicacion de desarrollador (App ID y Client Secret). La autorizacion es OAuth 2.0.

Una vez autorizado, se intercambian publicaciones, variantes, stock, pedidos y los datos de comprador y envio que envia Mercado Libre. Las credenciales y los tokens viven en tu base. Sin clave de activacion y sin servidor de terceros.

Preguntas frecuentes

Que hace falta para conectar?
Una cuenta de vendedor de Mercado Libre y una aplicacion de desarrollador con App ID y Client Secret.
Donde se guardan los tokens?
Solo en tu base de Odoo. No hay servidor de terceros ni clave de activacion.
Las ventas entran solas?
Si. Con los webhooks activos, cada venta genera el pedido, la entrega y la factura.
Como se elige la factura A o B?
Segun la condicion fiscal del comprador.
Se puede usar mas de una cuenta?
Si. El conector admite varias cuentas de Mercado Libre en la misma base.
Que pasa si el SKU no coincide?
Se puede usar un producto de respaldo para no frenar la factura.
