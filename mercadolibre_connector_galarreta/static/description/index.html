Privacidad

Servicio externo y datos

El modulo usa la API de Mercado Libre. Hace falta una cuenta de vendedor activa y una aplicacion de desarrollador (App ID y Client Secret).

Una vez autorizado, se intercambian publicaciones, variantes, stock, pedidos y los datos de comprador y envio que envia Mercado Libre. Las credenciales y los tokens viven en tu base. Sin clave de activacion y sin servidor de terceros.

Ayuda

Preguntas frecuentes

Que hace falta para conectar?
Una cuenta de vendedor de Mercado Libre y una aplicacion de desarrollador con App ID y Client Secret.
Donde se guardan los tokens?
Solo en tu base de Odoo. No hay servidor de terceros ni clave de activacion.
Las ventas entran solas?
Si. Con los webhooks activos, cada venta genera el pedido, la entrega y la factura.
La factura vuelve a Mercado Libre?
Si. Al confirmarla, el PDF se sube al pack de la venta.
Se puede usar mas de una cuenta?
Si. El conector admite varias cuentas de Mercado Libre en la misma base.
Que pasa si el SKU no coincide?
Se puede usar un producto de respaldo para no frenar la factura.
